# Product photography

Real product photos go here for reference; actual product images are
served from `storage/app/public/products/` via `Media` rows. The
development dataset's product photos are placeholder SVGs generated by
`App\Support\PlaceholderMedia::productImageSvg()` at seed time — nothing
to replace here yet, just upload real photos through the (future) admin
UI once it exists, or seed them the same way this dataset does.
