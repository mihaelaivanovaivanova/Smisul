# Product videos

Real product demo videos go here for reference. The development
dataset attaches one placeholder video `Media` row (on Smisul Original)
so the storefront's video UI path is exercised — the file itself is a
plain-text stub generated by
`App\Support\PlaceholderMedia::videoPlaceholderText()`, not a real
playable video (no encoding tooling was available to produce one). Drop
a real video at the same storage path, or update the `Media` row's
`path`, to replace it.
